# 命令入口

完整参数以 `remote-agent-session help` 和 [接续指引](internal/buildinfo/references/session.md) 为准。

- 本机服务：start、stop、restart、status、doctor、service-install、service-remove、service-forget。
- 认证：config set/show、login、login finish、logout。
- 原会话：session attach/status/detach、session hooks、session plugin install/remove/check。
- 产品说明：skills read [setup|session]、version。
